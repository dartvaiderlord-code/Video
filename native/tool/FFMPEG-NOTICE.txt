Abordage uses FFmpeg as a separate executable, not a linked library.
This distribution includes an unmodified static GPL FFmpeg 7.1.1 Windows build
provided by Gyan Doshi (www.gyan.dev), released on 2025-03-10.
Please read the upstream LICENSE, README.txt and documentation included here.
Exact archive URL, SHA-256 and distribution provenance: build-provenance.json.
Upstream binary distribution:
https://github.com/GyanD/codexffmpeg/releases/tag/7.1.1
FFmpeg source revision, as identified by the upstream README.txt:
https://github.com/FFmpeg/FFmpeg/commit/db69d06eee
Build configuration and enabled dependencies are recorded in README.txt and in
  ffmpeg -buildconf
FFmpeg source is available at the source URL above (git checkout db69d06eee).
Upstream build information: https://www.gyan.dev/ffmpeg/builds/
No modifications have been made to the FFmpeg binary in this distribution.
FFmpeg is distributed without warranty. GPU encoding also needs the respective
vendor driver. The transport itself does not depend on FFmpeg's network stack:
only local loopback UDP carries MPEG-TS to/from Abordage's encrypted transport.
